# Taskora

## App Summary
Taskora is a simple project and task manager built for freelancers and solo professionals. It helps you organize client work, track time and estimated hours, and keep an eye on your earnings—all from one place.

## Problem Statement
Freelancers often manage multiple projects at the same time, and keeping track of tasks, deadlines, hours, and payments becomes messy across notes, spreadsheets, and chat apps. This leads to missed deadlines, inaccurate estimates, and unclear progress—especially when work is split across several clients.

## Solution
Taskora brings projects, tasks, and time/earnings tracking into a single workflow. You create projects, add tasks with priority and estimated hours, and monitor progress and totals so you always know what’s done, what’s next, and what you’re earning.

## Key Features (Initial List)
- Onboarding flow to introduce the app quickly
- Authentication (Login / Sign Up)
- Forgot password flow (Email → Code → Reset password)
- Dashboard overview (projects, tasks, hours, earnings snapshot)
- Projects management (create, view list, view details, edit, delete)
- Tasks management (create, view details, edit, delete)
- Task status tracking (e.g., To Do / In Progress / Done)
- Priority levels (Low / Medium / High)
- Estimated hours per task
- Hourly rate support (per task or project input)
- Profile screen (basic user info + quick stats)
- Error states (No internet / Server error) with retry actions

## Value Proposition
- **Clarity in one place:** Projects, tasks, progress, and earnings are organized in a clean, focused layout.
- **Better planning:** Priorities + estimated hours help you plan your week and avoid overbooking.
- **More control:** You can track work progress and understand your time value, making decisions faster and pricing more confidently.
